# SDHP Project – Agent Memory

## Overview
State-Dependent Hawkes Process (SDHP) estimation for electricity market order-book data.
Two event types: H (hourly delivery) and Q (quarter-hourly delivery). Two states: 0=Normal, 1=Stressed.

## Source files in `src/`

| File | Purpose |
|------|---------|
| `sdhp_models.py` | Dataclasses, branching matrix, spillover, param↔vector conversions, initialization |
| `likelihood_exp.py` | O(n) recursive log-likelihood for n-Exp kernels (EXP1/EXP2/EXP3) + FD gradient |
| `likelihood_powerlaw.py` | Truncated (delta_max=1800 s) power-law log-likelihood + FD gradient |
| `optimization.py` | L-BFGS-B multi-start session estimation; `estimate_session` / `estimate_all_sessions` |
| `residuals.py` | Time-rescaled residuals, KS / Ljung-Box / Wasserstein-1 diagnostics |

## Key design decisions

### Parameter encoding (log-space)
- `params_to_vector_exp`: `[log(mu).ravel(), log(alpha).ravel(), log(beta).ravel()]`
  - mu shape (2,2), alpha/beta shape (2,2,2,n_comp) → flat vector of length 4 + 2·16·n_comp
- `params_to_vector_powerlaw`: `[log(mu), log(alpha), log(eta-1), log(c)]`
  - Fixed length 28 (4+8+8+8)

### Recursive running sums R[x, e', e, r]
All N_STATES R-sum arrays are updated at every event (regardless of current state).
Intensity in current state x uses only R[x, …]:
`λ_e(t) = μ[x,e] + Σ_{e',r} R[x,e',e,r]`
Decay step: `R *= exp(-β * dt)` — fully vectorised over (N_STATES,2,2,n_comp).

### Compensator with regime-switching
Each sub-interval [t_a, t_b] in state x_seg contributes:
`Λ_e += μ[x,e]·dt + Σ_{e',r} R[x,e',e,r] / β[x,e',e,r] · (1 − exp(−β·dt))`
where R is evaluated **before** this segment's decay.

### Spectral-radius penalty
`P(θ) = Σ_x ω · max(0, ρ_x − ρ*)²`
`ρ* = 0.95`, `ω = 1000`
For power-law: branching matrix entry = `α · ∫₀^{δ_max} (τ+c)^{−η} dτ` (analytical).

### L-BFGS-B bounds (log-space)
| param | raw range | log-space |
|-------|-----------|-----------|
| μ | [1e-4, 10] | [-9.21, 2.30] |
| α | [1e-4, 500] | [-9.21, 6.21] |
| β | [1e-4, 1000] | [-9.21, 6.91] |
| η−1 | [0.01, 10] | [-4.61, 2.30] |
| c | [1e-3, 3600] | [-6.91, 8.19] |

### FitResult fields
`neg_log_lik`: penalised; `nll_per_event = (neg_log_lik − penalty) / n_events_total` (unpenalised per event).

## Conventions
- Event type index: 0=H, 1=Q
- State index: 0=Normal, 1=Stressed
- `state_path`: shape (n_obs, 2) = [time_sec, state]; piecewise-constant, sorted by time
- Times in **seconds** from session start (session_start=0.0)
- `h_rate`, `q_rate` are in **events/second** for initialization

## Diagnostics (residuals.py)
Four residual streams per session: H-Normal, H-Stressed, Q-Normal, Q-Stressed.
Residuals filtered by state at event time, after 5-event burn-in.
Dict keys use prefix pattern: `{h|q}_{normal|stressed}_{ks_stat|ks_pval|ks_pass|lb_stat|lb_pval|lb_pass|w1_dist}`.

## Dependencies
- numpy, scipy (stats + optimize), statsmodels (acorr_ljungbox)

## Experiment 2 – Key Run Notes (exp_2_kernel_comparison.py)

### Inputs
- Reads `results/exp1_sessions.pkl` (19 synthetic sessions produced by Exp 1).
- No CLI arguments; `max_sessions=20` is hard-coded at `__main__`.

### Outputs (all written to `results/`)
| File | Description |
|------|-------------|
| `exp2_fits.pkl` | All 76 FitResult objects (19 sessions × 4 kernels) |
| `exp2_results.csv` | Flat DataFrame with one row per fit |
| `exp2_comparison_table.csv` | Per-kernel summary table |
| `exp2_nll_boxplot.png` | NLL/event boxplot by kernel |
| `exp2_convergence.png` | Convergence-share bar chart vs paper targets |
| `exp2_comparison_heatmap.png` | Heatmap of convergence_share and nll_median |
| `exp2_run_full.log` | Full run log (tee'd by caller) |
| `RESULTS.md` | Metrics **appended** (not overwritten) each run |

### Runtime (synthetic data, 19 sessions, numba JIT cached)
- 3-Exp kernels (3 starts, analytical gradient): ~27 s total
- Power-law (1 start, FD gradient, 300 func-evals budget): ~3.5 min total
- **Total wall time ≈ 4 min** (numba cached; first run adds ~1-2 s JIT compile)

### Known quirks
- `_write_exp2_metrics` uses `open(..., 'a')` → RESULTS.md gets a new
  Experiment 2 block appended on every run; old blocks are not removed.
- Power-law FD gradient budget (300 func-evals, 200 iter) is intentionally
  small to limit runtime; 6/19 sessions hit the iteration limit.
- Seaborn FutureWarning about `palette` without `hue` is benign (cosmetic).
